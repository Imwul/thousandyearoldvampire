## 범위와 결과

- 기본 프롬프트 80개, 방문 항목 222개를 PDF p32–111과 대조했다. 1–71번은 각 3방문, 72–80번은 각 1방문이다. 페이지는 `번호 + 31`이다.
- Appendix I의 번호별 묶음과 방문 들여쓰기를 PDF p113–150에서 다시 추출하고, 각 묶음을 한국어로 옮겼다. 고유 인쇄 번호는 1–135이나 74가 두 번 쓰였다. 이를 분리하면 **136묶음, 265방문**이다.
- PDF p133의 번호 없는 대체 엔딩 5개도 보존했다. 선택 가능한 전체 대체 항목은 **141개, 270방문**이다.
- 기본/대체 번호, 원본 페이지, 방문 수, 한국어 문자열 누락, 중복 앱 ID, 엔딩/경험 메타데이터의 방문 범위를 검사했다. PDF p133과 p134는 실제 이미지로도 확인했다.

이 문서는 콘텐츠 대조 결과다. 게임의 상태 변경과 저장 동작 검증은 `RULES_AUDIT.md` 및 도메인 테스트에서 별도로 다룬다. 서술적 판단이나 분기 선택을 자동으로 확정한다는 뜻은 아니다.

## 고친 내용

기존 대체 데이터는 방문 문단을 별도 번호로 평탄화하여 5번부터 원본 번호와 어긋났다. 후반부에는 빠진 묶음, 임의 확장과 다른 번호의 내용을 섞은 항목도 있었다. 실제 번호별 `entries`를 복원했다. 특히 88번은 3방문이 아니라 **6방문**이다.

기본 데이터는 80개가 있었으나 후반부에 원문에 없는 세부 설정이 들어갔다. 예를 들어 72번은 밖에서 파괴되는 이유를 태양으로 확정하지 않고, 75번은 살해 방법을 말뚝으로 확정하지 않으며, 80번은 높은 차원으로 옮겨가는 일을 신이 되는 것으로 확정하지 않는다. 26.3의 전 인류가 흡혈귀를 안다는 결과는 자원 3개를 잃을 수 없어 도망친 분기에만 적용된다. 39.3에 덧붙였던 임의 대체 지시도 제거했다.

## 추가로 보존한 특수 지시

기본 10.2의 유물에 따른 엔딩 재작성, 33.2의 슬롯 밖 영구 기억, 48.3의 꿈 세계와 10번 복귀, 51.3의 노화하지 않는 필멸자, 52.1의 용도 제한 추가 기억 칸을 원문 의미대로 유지했다.

대체 항목의 기억 문장/단어 변형, 별도 일기장과 평판 저장소, 일시적·지속적 주사위 변경, 특정 페이지에 미래 사건/자원/인물 예약, 88번의 6방문, 133.3의 두 인물 플레이, 134번의 슬롯 밖 영구 경험, p133의 다음 시즌 지시도 삭제하거나 일반 규칙으로 덮어쓰지 않았다. 이러한 특별 지시는 플레이어가 해당 분기를 선택하고 기록을 편집할 때 따른다.
