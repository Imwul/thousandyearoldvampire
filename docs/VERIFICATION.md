## Chrome에서 실제 조작

별도 브라우저 프로필의 로컬 개발 서버에서 확인했다. 실제 사용자 기록과 원격 계정은 사용하지 않았다.

- 예시 인물의 생성, 다섯 초기 경험, 기술 추가, 등장인물 사망 표시.
- 작성 중인 연대기·경험의 새로고침 복구, 기록 완료, 주사위 이동.
- 경험과 연대기를 함께 저장하고, 완료한 사건의 중복 기록을 막는 흐름.
- 일기장의 네 기억 한도, 자동 생성되는 자원, 분실 시 연결 기억의 소실과 읽을 수 있는 과거 기록.
- 원서의 중복 74b 대체 사건 선택, 새로고침 후 연결 유지, 기본 사건 복귀.
- 개별 사건이 허용하는 별도 일기장 생성.
- 평화 결말, 같은 인물의 다음 시즌, 사건 0 재개, 이전 방문 이력 유지, 추가 기억 칸과 특성.
- 합산 주사위의 실제 수식과 결과 표시.
- 초안을 포함하는 JSON 가져오기, 내보내기.
- 1440px, 768px, 390px, 320px에서 문서 전체의 가로 넘침 없음. 설정·플레이·규칙 화면 확인.
- Geist·SUIT 두 글꼴의 로컬 로드, 한국어 입력 크기 16px, 런타임 JavaScript 오류 없음.

## 검증의 범위

Google 실계정 로그인 및 실제 Firestore 권한·네트워크 동기화는 수행하지 않았다. 로그인 실패·권한 오류는 기기 저장을 유지하고 안내하도록 구현했다. 클라우드 충돌 시 양쪽 복구본을 남기고 사용할 기록을 선택한다.

프롬프트의 서사적 선택과 조건 판정은 플레이어가 적용한다. 다인 플레이의 실시간 공유 캠페인 서버는 제공하지 않는다. 이 범위는 앱의 규칙 안내와 규칙 대조 문서에도 명시했다.

## 디자인 재검토

룰북 표지의 검은 제본과 적색 제목표를 참고해 무채색 바탕·버건디 강조색으로 다시 구성했다. 달·궤도 그림과 장식 서체를 제거하고 Geist·SUIT를 로컬 제공한다. 상단·통계·제목의 높이를 줄이고 집필 영역을 넓혔으며 모바일 기억 목록은 접어 열 수 있다. 1440/1024/768/390/320px 가로 넘침 없음, 글꼴 로드·그림 제거·기억 접기 조작을 브라우저에서 확인했다.
