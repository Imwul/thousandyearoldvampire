# 천년의 기록

Tim Hutchings의 *Thousand Year Old Vampire*를 위한 한국어 솔로 플레이 기록 도구. 소장한 룰북 1.2판과 함께 사용합니다.

```sh
npm ci
npm run dev
```

`npm run build`는 TypeScript 검사와 배포용 번들을 생성합니다. `npm run lint`는 미사용 선언, TypeScript, ESLint, React Hooks를 검사합니다. `npm test`는 룰 엔진과 사건 카탈로그의 회귀 테스트를 실행합니다.

## 기록과 진행

- 빠른 게임과 저널링 게임을 지원합니다. 새 경험을 기억에 넣고 사건의 지시를 기록표에 반영한 뒤 다음 주사위를 굴립니다.
- 기본 규칙은 앱이 검증합니다. 이야기의 해석과 특성의 선택은 플레이어가 결정하며, 개별 사건의 예외는 ‘사건의 특별한 지시 적용’에서 처리합니다.
- 기본 사건 80개와 부록 대체 사건·결말 141개를 제공합니다. 원서에서 중복된 74번은 `74a`와 `74b`로 구분합니다.
- 기록과 작성 중인 글은 기기에 자동 저장됩니다. JSON 파일로 내보내고 다시 불러올 수 있습니다.
- Google 로그인 시 기존 Firebase 프로젝트에 동기화합니다. 다른 기록이 발견되면 사용할 기록을 선택할 때까지 업로드를 멈춥니다.
- 글꼴은 `public/fonts`에 포함되어 외부 폰트 서버에 의존하지 않습니다. 각 글꼴의 라이선스와 출처도 함께 보관합니다.

룰북 대조 근거와 수동 판정의 범위는 [규칙 검토](docs/RULES_AUDIT.md), 사건별 페이지·문단 검토는 [사건 검토](docs/PROMPT_AUDIT.md), 검증 결과는 [검증 기록](docs/VERIFICATION.md)을 참고하세요.

Vercel의 기존 `dist` 배포 설정을 유지합니다. 룰북 PDF 원본과 개인 저장 파일은 저장소에 포함하지 않습니다.
