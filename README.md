# 천년의 기록

Tim Hutchings의 *Thousand Year Old Vampire*를 위한 한국어 솔로 플레이 기록 도구. 소장한 룰북 1.2판과 함께 사용합니다.

```sh
npm ci
npm run dev
```

`npm run build`는 TypeScript 검사와 배포용 번들을 생성합니다. `npm run lint`는 미사용 선언, TypeScript, ESLint, React Hooks를 검사합니다. `npm test`는 룰 엔진·사건 카탈로그·저장 경계의 회귀 테스트를 실행합니다.

## 기록과 진행

- 빠른 게임과 저널링 게임을 지원합니다. 새 경험을 기억에 넣고 사건의 지시를 기록표에 반영한 뒤 다음 주사위를 굴립니다.
- 기본 규칙은 앱이 검증합니다. 이야기의 해석과 특성의 선택은 플레이어가 결정하며, 개별 사건의 예외는 ‘사건의 특별한 지시 적용’에서 처리합니다.
- 기본 사건 80개와 부록 대체 사건·결말 141개를 제공합니다. 원서에서 중복된 74번은 `74a`와 `74b`로 구분합니다.
- 기록과 작성 중인 글은 기기에 자동 저장됩니다. 초안은 인물·사건·방문별로 보관하며, 저장 실패 시 상단과 알림에 표시합니다.
- JSON으로 현재 인물과 작성 중인 초안을 백업·복원하거나 Markdown 읽기 문서를 받을 수 있습니다. 인물 생성 전 시작 초안도 포함합니다.
- ‘기기 복구함’에서 교체 전 기록·클라우드 선택 전 기록·이전 집필 초안을 회수합니다. 손상된 원본도 다운로드할 수 있습니다. 기기 복구본은 항목별 최신 한 개이며, 장기 보관은 파일 백업을 사용하세요.
- Google 로그인 시 기존 Firebase 프로젝트에 동기화합니다. 서버의 기록을 확인한 뒤 동기화하며, 거래 안에서 서버 변경을 다시 확인합니다. 다른 기록이 발견되면 사용할 기록을 선택할 때까지 업로드를 멈춥니다. 작성 중인 집필 초안은 기기와 JSON 파일에만 보관하며 클라우드 자동 동기화 대상에는 포함하지 않습니다.
- 글꼴은 `public/fonts`에 포함되어 외부 폰트 서버에 의존하지 않습니다. 각 글꼴의 라이선스와 출처도 함께 보관합니다.

룰북 대조 근거와 수동 판정의 범위는 [규칙 검토](docs/RULES_AUDIT.md), 사건별 페이지·문단 검토는 [사건 검토](docs/PROMPT_AUDIT.md), 검증 결과는 [검증 기록](docs/VERIFICATION.md)을 참고하세요.

Vercel의 기존 `dist` 배포 설정을 유지합니다. 룰북 PDF 원본과 개인 저장 파일은 저장소에 포함하지 않습니다.
